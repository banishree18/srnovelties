# SR Novelties

Online order system for SR Novelties, a kids' gifts, stationery and ladies fashion shop in Hyderabad.

## How it works
- `index.html`: landing page showing live products and taking orders
- `Apps_script/Code.gs`: Google Apps Script that reads the Inventory tab and saves
orders into the "SR Novelties Master" Google Sheet

## Updating the Apps Script
Code.gs is copied manually from the Apps Script editor.
After editing, paste it back into the editor and redeploy:
Deploy → Manage deployments → Edit → New version.
